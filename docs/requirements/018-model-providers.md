# 需求文档 · 模型供应商管理(M29 · Model Providers)

- 文档版本:v0.1(20261008 初稿并当日交付;决策 1/2 经确认,3 维持范围外)
- 对应主需求:001 §F2(LLM 网关)增量演进;参考 WorkBuddy / Trae 模型管理
- 对应设计:[023-model-providers.md](../design/023-model-providers.md)
- 变更记录:20261008 初稿

## 1. 背景

平台已有三源模型目录(个人端点 / 平台共享 / 网关默认)与后端按名路由
(`resolve_endpoint`:用户自定义优先),但体验对标 WorkBuddy/Trae 有三缺口:

1. **无供应商概念**:自定义端点一条=一个模型,换 3 个模型要建 3 条、重复填
   base_url/key;没有常用厂商预设
2. **配置无验证**:key 填错只有到对话时才失败;模型名手填易错,无列表发现
3. **选择器够不着**:会话模型下拉只有网关 auto 池——**用户自定义了模型,
   会话里却选不到**(核心缺口);配置入口藏在开发者中心,离使用处太远

WorkBuddy/Trae 的范式:默认官方托管模型开箱即用;模型选择器就在输入框旁,
底部「+ 添加自定义模型」直达;添加时选供应商预设 → 填 Key → **保存即验证**。

## 2. 用户故事

- 作为用户,开箱即用平台网关模型(auto 智能路由),不配置任何东西
- 作为用户,我添加一个供应商(如 DeepSeek):选预设 → 粘贴 Key → 平台验证连通
  并拉出我的可用模型列表 → 勾选我要用的
- 作为用户,会话模型下拉分三组:平台网关 / 我的各供应商模型;切换即时生效
- 作为用户,供应商 Key 改动/失效一目了然,可测试连通性

## 3. 验收标准

- **A1 默认不变**:不配置任何供应商时,行为与现状完全一致(网关 auto)
- **A2 供应商管理**:添加供应商(预设:火山方舟/DeepSeek/硅基流动/OpenAI/
  Anthropic/自定义)→ base_url 预填可改 → 填 Key(加密存储沿用 Fernet)→
  保存时**连通性验证**(拉模型列表;失败可保存为「未验证」并提示)
- **A3 模型发现**:验证成功展示该供应商可用模型列表供勾选(全选/搜索);
  拉不到列表(内网/非标准)可手填模型名
- **A4 会话选择器升级**:模型下拉三组(平台网关: auto+池 / 各供应商勾选模型 /
  平台共享);底部「+ 添加自定义供应商」直达添加弹窗;切换即时生效
- **A5 供应商运维**:列表/改名/换 Key(重新验证)/删除(连带其模型);Key 不回显
- **A6 兼容**:存量个人端点迁移为「导入的端点」供应商(每条一供应商,模型不变);
  助手 manifest 指定 model 的行为不变;CLI/SDK 无感

## 4. 范围外

- 供应商级用量/成本统计(insights 演进另立项)
- 按模型计费配额、团队共享供应商(admin 共享端点沿用现状)
- 非 OpenAI 兼容协议(Anthropic 原生协议等——经网关或兼容层解决)
- 模型能力标注(视觉/推理标签来自网关元数据,自定义模型手填)
