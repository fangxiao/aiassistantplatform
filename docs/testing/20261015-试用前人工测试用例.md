# 试用前人工测试用例(20261015 · 线下业务专家 + 错题本)

> 背景:首轮试用反馈"组件没渲染、回复不符合预期"。今天已修复一批渲染类问题
> (表格 headers 兼容、output_block 徽标、KaTeX 公式、mermaid 图、过渡语治理)。
> 本用例集用于人肉验证修复效果 + 完整业务流,**全部通过后再对外试用**。
>
> 测试入口:主聊天页 http://localhost:3000(或隧道域名)与白牌页 /a/{token}
> 勾选方式:通过打 ✅,失败记现象 + 会话链接(便于我用 hub show 溯源)

## A. 线下业务专家

### A1 纯文本业务问答(验:直接交付、无内心独白)
- [ ] 问:「100% 受托支付合规与资金分账方案」
- 预期:直接输出结构化方案正文;**正文开头没有**"用户在询问…让我调用…"式元思考
- 预期:方案说明卡片(type=card)正常渲染出内容(不是只有标题或空白)

### A2 指标计算(验:metric_stat 组件)
- [ ] 问:「客单价 3 万、毛利率 30%、月销 50 单,做商户贴息 5% 的 ROI 测算」
- 预期:核心指标(单量/利润/ROI)渲染为**指标看板卡片**,数字与手算一致

### A3 多方案对比(验:table 组件 + 今日修复)
- [ ] 问:「对比等额本息与先息后本在场景分期下的适用性,表格呈现」
- 预期:**表格正常渲染出表头和行**(此前 headers 形态会整表空白);有标题栏;可点列排序

### A4 流程/链路分析(验:waterfall 组件)
- [ ] 问:「从进件到放款的各环节耗时拆解」
- 预期:流程耗时渲染为**时序流组件**(非纯文本)

### A5 Mermaid 图(验:今日新增)
- [ ] 问:「微信 H5 进件唤醒支付宝人脸核身的断点续填链路,用时序图表示」
- 预期:渲染为**矢量时序图**(非原始代码);若看到"图表渲染异常"+源码属降级保护,记为半过

### A6 数学公式(验:KaTeX)
- [ ] 问:「推导贴息场景下资方净息差(NIM)的计算公式」
- 预期:块级 $$ 公式渲染为数学排版;行内 $…$ 同样;**无 $ 符号裸露**

### A7 表单边界(验:output_block input.form 纪律)
- [ ] 问:「帮我梳理线下现金贷的风控策略框架」(开放性咨询)
- 预期:**不弹表单**,直接输出完整方案
- [ ] 问:「帮我测算一笔分期还款」(测算场景,缺参数)
- 预期:弹**输入表单**;填写提交后对话自动续跑给出结果

### A8 Excel 附件解读(验:docx/xlsx 解析 + 个人库挂载)
- [ ] 上传一份还款计划 xlsx → 问「解读一下这个文件」
- 预期:模型能引用文件里的具体数字(不是"我看不到文件")
- [ ] 把该文件「入库 → 我的知识库」后,**新开会话**直接问「我上传的还款计划里第 3 期金额是多少」
- 预期:个人库自动挂载,无需再传文件即可回答

### A9 长回复截断(验:M41 截断显性化)
- [ ] 问:「完整分析线下场景分期的获客-风控-贷后全链路,尽量详细」
- 预期:若被截断,末尾出现「⚠️ 回复因达到最大输出长度被截断…可回复继续」;回复「继续」能接着输出(不是重新答一遍)

### A10 工具徽标与过渡语(验:M41 过渡语治理 + 折叠)
- [ ] 触发工具的问答中,顶部徽标显示语义化名称(📊 数据表格/📋 方案卡片),**不出现**"给出了填写表单"
- [ ] 连续多次检索时折叠为「🔍 信息搜索(n 次已完成)」单行,可展开
- [ ] **刷新页面回看**:正式消息里没有过渡语/内心独白残留;组件仍正常渲染

## B. 错题本(白牌页轻注册账号)

### B1 文字录入
- [ ] 输入一道完整错题(题面+错解+正解+错因)
- 预期:返回「已录入」+ 下次复习日期(日期由工具返回,**模型不得自造**)

### B2 图片录入(验:多模态 + 带图录入)
- [ ] 粘贴一张题目截图 → 要求录入
- 预期:模型读图转写题面并录入;用户消息气泡回显缩略图;录入成功消息含「已附题图」

### B3 Excel 错题清单(验:xlsx 解析 + 入库)
- [ ] 上传错题清单 xlsx → 要求批量录入
- 预期:按行解析逐题录入(或说明策略);条数与文件一致

### B4 复习闭环
- [ ] 问「今天有什么到期错题」→ 生成复习卷:**只给题面不给答案**,卷末有核对区
- [ ] 反馈作答结果 → 答对进阶(第 2 轮)/答错回炉(第 1 轮),返回下次复习日期
- [ ] 故意把「1+1」答错 → 该题回炉,明天再到期

### B5 学情汇总
- [ ] 问「汇总一下我的学情」→ 学科分布/错因 TOP/到期数,数字与实际录入一致(不编造)

### B6 职责边界
- [ ] 问「给我生成今日单词表」(域外请求)
- 预期:礼貌拒绝/引导,**不**录入错题、**不**产出别的内容

### B7 数据隔离(两账号)
- [ ] 账号 A 录入的错题,账号 B 的「我的」→ 我的文件/对话里看不到

## C. 平台通用

- [ ] 工作台各中心(会话/任务/待办/我的文件)只显示最近 5 条 + 「查看全部」跳转正常
- [ ] 上传 >5MB 文件 → 出现琥珀色提醒(不静默消失);上传中有进度条;**进度中按发送被拦截**
- [ ] 分享链接打开:只读正常;底部「用这个助手开始我自己的对话」→ 轻注册 → 自己的工作台可用
- [ ] 手机视口(或真机):白牌页聊天 + 附件 + 我的抽屉全流程可走
